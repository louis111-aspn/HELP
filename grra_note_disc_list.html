3.2.1 개별주석작성리스트

개별주석작성리스트

주석양식의 메뉴를 트리 계층구조로 조회하고, 각 메뉴(양식 L)의 개별주석 입력화면으로 이동하는 진입점 화면입니다. 주석입력상태 아이콘으로 각 메뉴의 데이터 입력 현황을 한눈에 파악할 수 있습니다.

메뉴 경로
ASPN 주석관리 > 개별주석 관리 > 개별주석작성 리스트

선행 조건: 해당 메뉴의 레이아웃(행·열)이 레이아웃관리(3.1.2)에서 구성되어 있어야 입력링크가 활성화됩니다. 레이아웃 미구성 메뉴는 "해당 메뉴의 레이아웃이 없습니다" 알림창이 표시됩니다.

2

메뉴 트리 목록 확인

조회된 양식의 메뉴 계층구조가 트리 형태로 표시됩니다.

▼ FINS01  금융상품 [노드]
┝ FINS0101  금융비용의 내역 [양식] ● 입력됨 → [입력링크]
┝ FINS0102  이자비용 [양식] ● 입력됨 → [입력링크]
┝ FINS0103  매출채권의 채권연령분석 [양식] 미입력 → [입력링크]
└ FINS0104  매출채권 및 기타 채권구분 [양식] 미입력 → [입력링크]

3

입력링크 — 개별주석 입력 화면 이동

[입력링크]를 클릭하면 새 탭에서 해당 메뉴의 개별주석 입력 화면이 열립니다.
  • 1
    양식(L) 메뉴의 [입력링크] 클릭
    레이아웃이 구성된 양식 메뉴에만 [입력링크] 버튼이 활성화됩니다. 클릭 시 새 탭이 열리면서 해당 메뉴의 개별주석 입력화면으로 이동합니다.
  • 2
    조회 조건 전달
    리스트 화면의 조회 조건(주석양식ID·메뉴ID·연결단위·회계연도·회계기간)이 입력 화면으로 전달됩니다. 이 중 주석양식ID·메뉴ID는 변경 불가이며, 연결단위·회계연도·회계기간은 입력 화면에서 변경 가능합니다.
⚠ 레이아웃 미구성 시: 해당 메뉴의 레이아웃이 없으면 [입력링크] 버튼이 비활성화됩니다.
4

개별주석 입력 및 저장

레이아웃 구성에 따른 그리드에 주석 데이터를 입력하고 저장합니다.
  • 1
    입력 화면 진입 시 자동 조회
    첫 화면 진입 시 기존 데이터가 자동 조회됩니다. 레이아웃관리에서 구성한 행·열 구조로 그리드가 표시됩니다.
  • 2
    데이터 입력
    그리드 셀에 주석 내용을 입력합니다. Ctrl+셀 선택 후 Ctrl+V로 엑셀 복사·붙여넣기가 가능합니다. 그리드 구성(행/열) 변경은 이 화면에서 불가하며 레이아웃관리 앱에서만 수정 가능합니다.
  • 3
    검증 (선택)
    레이아웃관리에서 입력참조(SELECTION)를 설정한 경우, 해당 재무제표 항목의 전표 내역을 기반으로 입력값을 검증합니다.
  • 4
    [데이터 저장] 클릭
    입력된 데이터가 (개별주석입력 테이블)에 DATATYPE='I'로 저장됩니다.
  • 5
    [엑셀 익스포트] (선택)
    입력된 주석 내용을 엑셀 파일로 다운로드할 수 있습니다.
📌 열 숨김 적용: 양식 및 메뉴관리에서 HIDE_COL='Y'로 설정된 메뉴는 입력 화면에서 첫 번째 열이 자동으로 숨겨집니다.
⚠ 마감 후 입력 불가: 주석작성 모니터(3.2.2)에서 해당 메뉴가 마감(CSTAT='Y') 처리된 경우 작성 및 편집이 불가합니다.

데이터 저장 로직

개별주석 입력 데이터의 저장 방식입니다.
📋 저장 시 적용 규칙

• DATATYPE='I'로 고정 저장 (A·G·M은 저장 불가)
• ROW_ID(행아이디)와 열 레이아웃의 FIELDTYPE을 조합하여 대응 필드에 저장
• 통화값(CURR)='L'인 경우 연결단위의 로컬통화 자동 적용
• AMT01은 CURR01, QUAN01은 UNIT01 참조 저장

💱 거래통화(T) 저장 로직

통화구분='T'인 열은 TXT 타입 열의 값(통화코드)을 REF_TXT 설정에 따라 CURR 필드에 반영합니다.
예: AMT01의 REF_TXT=TXT03이면, TXT03에 입력된 'USD'를 CURR01에 저장한 후 금액을 AMT01에 저장합니다.
