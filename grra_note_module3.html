Group 3.2
개별주석 관리
개별 법인 담당자가 각 메뉴의 주석 데이터를 입력하고, 작성 완료 시 마감 처리합니다.
2개 프로그램
📋
3.2.1
개별주석작성리스트
주요 기능핵심 내용
메뉴 트리 조회양식ID 기준 메뉴를 계층 구조로 조회. 주석입력상태(●/공란) 표시
입력링크레이아웃이 설정된 양식(L) 메뉴에 [입력링크] 활성화 → 새 탭에서 입력 화면 열림
주석 입력행·열 그리드에 AMT/TXT/QUAN/DATE 등 입력. DATATYPE=I로 저장
저장통화구분 L: 연결단위 로컬통화 자동참조 / T: REF_TXT 열 통화 참조
엑셀 엑스포트 / 검증입력 데이터 다운로드 및 재무제표 항목 기준 검증

주석작성 모니터
주요 기능핵심 내용
메뉴별 진행률(작성완료 ÷ 작성대상) × 100. 진행률 100%이면 [마감취소], 미만이면 [마감] 활성
법인별 마감상세 화면에서 연결단위별 CSTAT를 Y(마감) 또는 공란(취소)으로 변경
메뉴별 일괄 마감해당 메뉴를 사용하는 전체 법인 일괄 마감
일괄마감/취소조회된 모든 메뉴 전체 법인 일괄 처리

3.3 — 연결주석 관리
🔗
Group 3.3
연결주석 관리
연결담당자가 개별 법인 데이터를 집계·환산·마감하고, 완성된 연결주석을 조회합니다. 환산수식은 FORMULA 설정 메뉴에 별도 수식을 정의합니다.
3개 프로그램
🖥️
3.3.1
연결주석모니터
주요 기능핵심 내용
집계마감된 법인 데이터 → 취합. ASTAT: 공란→N→Y
환산집계 데이터를 CONV(OPE/AVG/CLO/COPY/FORMULA)에 따라 GC 환산. VSTAT: 공란→Y
조정연결참조(GSELECTION) 기반 자동조정(A)/GR총금액(G) 데이터 불러오기
마감CSTAT=Y. 마감 후 집계·환산 불가. 개별주석모니터 마감 취소도 불가
도움말 열기 →
🔍
3.3.2
연결주석조회
주요 기능핵심 내용
조회링크양식(L) 메뉴에 [조회링크] 활성. 클릭 시 새 탭에서 조회 화면 열림
합산조회 (S)연결그룹 유효 법인 합산 내역. 합계조정(T) 시 수작업 조정 직접 입력 가능
법인별 조회 (Y)법인별 구분 조회. [법인별조회] 버튼으로 전환
LC금액 조회그룹통화 대신 법인별 로컬통화 금액으로 전환 조회
셀단위 조정 (C)DATATYPE 도움창(I/M/A)으로 데이터 유형 전환 조회
