3.3.3

환산수식관리

연결주석 환산 시 환산구분이 FORMULA로 설정된 행 또는 열에 적용할 사칙연산 수식을 정의하는 프로그램입니다. 수식멤버(결과값이 될 행/열)와 구성멤버(계산에 사용할 행/열), 연산자, 계산순서를 설정하여 환산 계산을 자동화합니다.

선행 조건: 주석 레이아웃관리에서 해당 행(ROW) 또는 열(COL)의 환산구분(CONV)을 FORMULA로 설정해야 이 화면에서 수식을 지정할 수 있습니다. FORMULA로 설정된 행/열만 리스트에 조회됩니다.
1

선행 작업 — 레이아웃에 FORMULA 설정

주석 레이아웃관리에서 수식 환산 대상 행/열의 CONV 값을 FORMULA로 설정합니다.
  • 1
    주석 레이아웃관리 실행
    주석 레이아웃관리 앱에서 수식을 적용할 양식ID와 메뉴ID를 선택하여 실행합니다.
  • 2
    행 또는 열 항목 선택 → 환산구분 FORMULA 입력
    수식 환산을 적용할 행(ROW) 또는 열(COL)의 속성 패널에서 환산구분(CONV) 필드에 FORMULA를 입력하고 [적용]을 클릭합니다.
  • 3
    레이아웃 저장
    설정 완료 후 레이아웃 저장을 클릭하여 테이블에 CONV='FORMULA'로 저장합니다.
📌 환산 기준 결정: 양식 및 메뉴관리의 행 우선 환산(ROW_CONV) 설정에 따라 행 또는 열 중 어느 쪽의 CONV 값이 적용될지 결정됩니다. ROW_CONV=Y이면 행의 CONV, N이면 열의 CONV가 우선 적용됩니다.
2

리스트 조회

FORMULA로 설정된 행/열 목록을 조회합니다.
  • 1
    주석양식ID 선택 후 실행
    도움창으로 주석양식ID를 선택하고 실행을 클릭합니다. 해당 양식에서 CONV='FORMULA'로 설정된 행·열 목록이 그리드에 표시됩니다.
  • 2
    수식입력상태 확인
    각 수식멤버의 수식입력 여부를 확인합니다. 수식이 입력된 경우 ●, 미입력 시 공란으로 표시됩니다.

리스트 그리드 컬럼

컬럼필드설명
메뉴IDMENU_ID
메뉴명ROWDE / COLDE
환산기준행/열 구분ROW_CONV=Y 이면 행, N 이면 열
수식멤버ROW_ID / COL_ID수식의 결과가 채워질 행 또는 열 ID
수식입력상태COUNT 기반● = 수식 있음 / 공란 = 미입력
> 버튼—클릭 시 해당 수식멤버의 입력 화면으로 이동
3

수식 입력 화면

> 버튼으로 진입하여 수식멤버에 대한 사칙연산 수식을 정의합니다.
  • 1
    > 버튼 클릭 → 세부사항 진입
    리스트에서 > 버튼을 클릭하면 해당 수식멤버의 수식 입력 화면이 열립니다. 상단에 주석양식ID·메뉴ID·수식멤버·Description 정보가 표시되며 변경 불가합니다.
  • 2
    Create 클릭 → 수식 행 추가
    Create 버튼을 클릭하여 수식 항목을 추가합니다. 한 수식멤버에 여러 구성멤버와 연산자를 계산순서에 따라 등록할 수 있습니다.
  • 3
    구분(CATEGORY) 선택
    Possible Entry 버튼으로 구분 값을 선택합니다. ALL은 모든 행/열에 공통 적용되는 수식, COL/ROW는 특정 행/열에만 적용되는 예외 수식입니다.
  • 4
    구성멤버·연산자·계산순서 입력
    구성멤버(BASE_MEM)는 수식멤버를 제외한 다른 행/열 ID를 Possible Entry로 선택합니다. 연산자(OPERATOR)는 +, -, *, / 중 선택합니다. 계산순서(CALC_SEQ)는 동일 수식멤버 내 계산 우선순위를 지정합니다.
  • 5
    수식 확인 → 수식변경
    입력된 수식을 확인하고, 변경이 필요하면 수식변경 버튼을 클릭하여 수정합니다. 수식 입력이 완료되면 이전 리스트 화면의 수식입력상태 컬럼에 ●(녹색)이 표시됩니다.

4

저장

입력된 수식 내용을 테이블에 저장합니다.
  • 1
    저장 클릭
    저장 버튼을 클릭합니다. 변경된 사항이 없으면 저장 버튼이 비활성화됩니다. "저장하시겠습니까?" 확인 후 테이블에 CATEGORY, FML_MEM, BASE_MEM, OPERATOR, CALC_SEQ가 저장됩니다.
📌 수식 변경 후 환산 재실행: 수식을 변경한 경우 연결주석모니터에서 해당 메뉴의 환산을 다시 실행해야 변경된 수식이 반영됩니다.
·

구분(CATEGORY) 코드

수식이 적용되는 범위를 지정합니다. 수식멤버가 ROW인지 COL인지에 따라 선택 가능한 값이 다릅니다.
ALL
전체 적용 (기본값)
수식멤버가 ROW이면 모든 열(COL)에, COL이면 모든 행(ROW)에 동일하게 적용되는 공통 수식입니다.
COL1, COL2…
특정 열에만 적용
수식멤버가 ROW일 때 사용. 특정 열에만 예외적으로 다른 수식을 적용할 때 지정합니다.
ROW1, ROW2…
특정 행에만 적용
수식멤버가 COL일 때 사용. 특정 행에만 예외적으로 다른 수식을 적용할 때 지정합니다.
📌 우선순위: 특정 행/열 지정 수식(COL2, ROW1 등)이 ALL보다 우선 적용됩니다. 즉, ALL로 공통 수식을 정의하고 예외적인 행/열만 별도 구분으로 지정하는 방식으로 구성합니다.
·

수식 계산 예시

수식멤버가 ROW인 경우와 COL인 경우의 계산 방식 예시입니다.

CASE 1 — 수식멤버가 ROW4 (행)인 경우

입력 데이터
구분COL1COL2COL3
ROW12005050
ROW21003020
ROW3502030
ROW4???
/* CATEGORY=ALL: 모든 열에 공통 수식 */
ROW4 = ROW1 × ROW3 ÷ ROW2
/* CALC_SEQ: 1=ROW1×ROW3, 2=÷ROW2 */

/* CATEGORY=COL2: COL2에만 예외 수식 */
ROW4(COL2) = ROW1 × ROW3
구분COL1 결과COL2 결과
ROW4200×50÷100 = 1050×20 = 1000

CASE 2 — 수식멤버가 COL4 (열)인 경우

입력 데이터
구분COL1COL2COL3COL4
ROW11503050?
ROW21003030?
/* CATEGORY=ALL: 모든 행에 공통 수식 */
COL4 = COL1 + COL2 - COL3

/* CATEGORY=ROW2: ROW2에만 예외 수식 */
COL4(ROW2) = COL1 - COL3
구분COL4 결과
ROW1150+30-50 = 130
ROW2 (예외)100-30 = 70
