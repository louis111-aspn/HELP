상각자산 스케줄 관리

상각자산 기준정보관리(기준정보)에 등록된 내부거래 자산에 대해 월별 감가상각 스케줄을 생성·관리하는 프로그램입니다. 일괄계산으로 전체 자산코드의 스케줄을 자동 산출하거나, 개별 상세 화면에서 법인세율 조정·재계산을 수행합니다. 스케줄이 확정되면 상각자산 전표제출 프로그램으로 연계하여 GR 전표를 생성합니다.

📌 조회 결과 범위: 다음 두 가지 조건에 해당하는 자산코드가 출력됩니다.

2

개별 스케줄 생성 (상세 화면)

조회 그리드에서 라인을 클릭하면 상세 화면으로 이동하여 월별 상각 스케줄을 확인하고 저장합니다.
  • 1
    라인 클릭 → 상세 화면 진입
    조회 그리드에서 개별 생성할 자산코드 라인을 클릭하면 상각스케줄 상세 화면으로 이동합니다. 기준정보(취득금액·상각기간 등)를 기반으로 월별 상각 내역이 자동 계산되어 표시됩니다.
  • 2
    이연법인세 적용 여부 확인 → 법인세율 입력
    이연법인세 적용 대상(ZCK_DEFTAX='X')이면 법인세율(%) 필드를 입력합니다.
  • 3
    상세 내역 확인 후 저장
    계산된 상각비·이연법인세·법인세비용 등 상세 내역을 확인하고 저장을 클릭합니다. 저장이 완료되면 조회 화면의 상각스케줄 아이콘이 초록색으로 변경됩니다.

3

재계산

선택한 거래코드의 전체 스케줄을 처음부터 다시 계산합니다.
  • 1
    상세 화면에서 재계산 클릭
    상세 화면 상단의 재계산 버튼을 클릭합니다. 현재 선택된 거래코드에 대한 전체 스케줄을 처음부터 다시 계산합니다.
  • 2
    추가거래 반영 확인
    추가거래(손상·처분)를 기준정보관리에서 등록한 후 재계산을 실행하면 해당 추가거래 내역이 스케줄에 반영됩니다.
  • 3
    저장
    재계산 결과를 확인한 후 저장 버튼을 클릭합니다. 저장하지 않으면 재계산 결과가 테이블에 반영되지 않습니다.
⚠ 재계산과 저장은 별개: 재계산 버튼 클릭만으로는 데이터가 저장되지 않습니다. 반드시 재계산 후 저장 버튼을 클릭해야 테이블에 반영됩니다.
4

재계산(당월)

선택한 특정 월 라인부터 상각 종료까지의 이연법인세·법인세비용을 재계산합니다.
  • 1
    재계산을 시작할 월 라인 선택
    상세 그리드에서 재계산을 시작할 월이 속한 라인을 클릭합니다.
  • 2
    재계산(당월) 클릭
    재계산(당월) 버튼을 클릭합니다. 선택한 월부터 상각 종료 월까지 이연법인세(TC·GC) 및 법인세비용(TC·GC) 필드가 재계산됩니다.
📌 재계산(당월) vs 재계산 차이점
재계산: 전체 스케줄을 처음부터 전부 재계산
재계산(당월): 선택한 월부터 종료까지만 이연법인세·법인세비용 재계산
⚠ 선택 월 이전 추가거래 반영 불가: 예를 들어 2024년 1월에 추가거래가 등록되어 있을 때, 2024년 2월 라인을 선택하여 재계산(당월)을 실행하면 해당 추가거래가 반영되지 않습니다. 추가거래가 등록된 월 이전의 라인을 선택하여야 해당 추가거래 내역이 반영됩니다.
5

일괄계산

조회 조건에 해당하는 자산코드 중 당월 전표가 없는 건에 대해 스케줄을 일괄 계산하여 저장합니다.
  • 1
    조회 조건 입력 후 실행
    일괄계산 대상을 조회합니다. 당월 회계전표가 이미 존재하는 거래코드는 자동으로 제외되고, 전표가 없는 건만 그리드에 표시됩니다.
  • 2
    일괄계산 클릭
    지정한 회계연도와 회계월 기준으로 시스템이 자동으로 상각 스케쥴을 계산합니다.
  • 3
    법인세율 자동 적용
    일괄계산 시 법인세율은 다음 기준으로 자동 적용됩니다.
    • 최초 스케줄 생성: 연결단위 마스터에 등록된 세율
    • 이미 세율 입력된 경우: 전월 세율 자동 참조
  • 4
    저장 — 기존 스케줄 재계산 후 갱신
    저장 시 해당 거래코드의 기존 스케줄을 삭제하고 재계산하여 다시 저장합니다. 단, 기준월보다 큰 월에 해당하는 스케줄만 삭제 후 재계산합니다.
📌 일괄계산 대상 제외 기준: 상각스케줄 중 하나라도 전표번호가 존재하는 거래코드는 일괄계산 대상에서 제외됩니다. 전표가 한 건도 없는 거래코드만 일괄계산 그리드에 조회됩니다.
⚠ 일괄계산 후 재실행: 일괄계산을 한 번이라도 실행한 거래코드는 이후 다시 일괄계산 대상으로 조회됩니다 (스케줄은 있지만 전표가 없는 상태이므로). 전표 생성 후에는 해당 거래코드는 대상에서 자동 제외됩니다.
6

편집 및 저장

상세 화면에서 편집 가능한 필드를 수정하고 저장합니다.
  • 1
    상세 화면 버튼 클릭 → 편집 활성화
    상세 화면 버튼을 클릭하면 편집 가능한 필드(상각비(TC)-조정, 법인세율)가 활성화됩니다.
  • 2
    값 수정
    법인세율 변경 시 이연법인세 및 법인세비용이 즉시 재계산됩니다. 상각비(TC)-조정 필드로 상각비를 수동 조정할 수 있습니다.
  • 3
    저장
    저장 버튼을 클릭하면 편집된 내역이 테이블에 저장됩니다. 저장 완료 메시지가 반환됩니다.
✏️ 편집 가능 필드

• 상각비(TC)-조정
• 법인세율(%)

🔒 편집 불가 필드

전표번호가 존재하는 라인의 법인세율은 편집이 제한될 수 있습니다. 전표 생성 후에는 해당 월의 스케줄 수정이 불가합니다.

7

삭제

거래코드에 대한 전체 스케줄 데이터를 삭제합니다.
  • 1
    상세 화면에서 삭제 클릭
    상세 화면에서 삭제 버튼을 클릭하면 현재 거래코드에 대한 전체 스케줄이 삭제됩니다.
🚫 삭제 불가 조건: 스케줄 중 하나라도 전표번호가 존재하면 삭제할 수 없습니다. 전표를 먼저 취소 처리한 후 삭제를 진행하세요.
📌 전표 취소 후 재처리: 전표제출 화면에서 전표를 취소하면 해당 월의 전표번호가 삭제 처리되어 스케줄 편집이 다시 가능해집니다. 이후 상각자산 전표생성에서 전표를 재생성할 수 있습니다.

이연법인세 계산 공식

법인세율 입력 시 자동 계산되는 이연법인세·법인세비용의 산출 공식입니다.
📌 계산 적용 조건: 이연법인세 적용 대상이고 전표번호가 없는 라인에 한해 계산이 실행됩니다.
① 이연법인세 (TC)
이연법인세(TC)
= 상각비잔액(TC) × 법인세율
상각비잔액(TC) × 법인세율
② 법인세비용 (TC)
법인세비용(TC)
= 전월 이연법인세(TC) − 당월 이연법인세(TC)
전월 이연법인세(TC)와 당월의 차액
③ 이연법인세 (GC) — KRW
이연법인세(GC) = 이연법인세(TC)
통화가 KRW인 경우 TC와 동일
③ 이연법인세 (GC) — 외화, 변동유형 A
이연법인세(GC)
= 이연법인세(TC) × (미실현손익_GC / 미실현손익_TC)
취득 시점의 TC/GC 비율 적용
③ 이연법인세 (GC) — 외화, 그 외
이연법인세(GC)
= 이연법인세(TC) × 기말환율(CLO)
기말환율(CLO) 적용
④ 법인세비용 (GC) — KRW
법인세비용(GC) = 법인세비용(TC)
통화가 KRW인 경우 TC와 동일

법인세비용(GC) 외화 계산 — 변동유형별

변동유형GC 법인세비용 계산 방식
