상각자산 전표 제출 및 승인

상각자산 스케줄 관리에서 확정된 스케줄을 GR(Group Reporting) 시스템에 전표로 전기하는 프로세스입니다. 제출자가 승인을 요청하고, 승인자가 결재를 처리한 후, 연결 모니터에서 태스크를 실행하여 최종 전표가 생성됩니다. 역할에 따라 화면 권한과 표시 버튼이 달라집니다.

전표 조회 모드🧑‍💼 제출자

이미 전표가 생성된 건을 확인할 때 사용합니다.
  • 1
    조회 조건에서 조회 모드 선택
    검색조건 중 조회 모드를 선택하면 이미 전표가 생성된 거래코드들이 조회됩니다.

    라인 상세 클릭 → 전표 내역 확인
    메인 그리드에서 라인의 > 버튼을 클릭하면 디테일 그리드에 전표 항목별 구체적인 내역(재무제표항목·그룹통화금액·장부통화금액·전표번호 등)이 표시됩니다.

3

승인요청🧑‍💼 제출자

전표 생성 대상 자산코드에 대해 승인자에게 결재를 요청합니다.
  • 1
    라인 선택 → 승인요청 버튼 활성화
    메인 그리드에서 승인요청할 자산코드 라인을 선택합니다. 승인요청 버튼이 활성화됩니다.
  • 2
    승인요청 버튼 클릭 → 확인 팝업
    "승인요청 하시겠습니까?" 확인 다이얼로그가 표시됩니다. 확인을 클릭하면 일괄처리가 진행됩니다.
  • 3
    승인자 선택 및 요청 내용 기입
    승인자를 선택합니다. 자신은 승인자로 선택할 수 없습니다. 승인 요청 내용을 기입합니다.
  • 4
    승인요청 완료 → 승인상태 S 업데이트
    요청이 완료되면 해당 자산코드의 승인상태(ZWSTATUS)가 S로 업데이트됩니다. 승인자에게 알람이 자동 발송됩니다.
⚠ 중복 요청 차단: 선택한 라인 중 이미 승인요청이 진행 중인(S 상태) 건이 포함되면 "이미 처리 중입니다" 메시지가 발생합니다.

    Launchpad 카운터 확인
    승인자의 Launchpad에서 상각자산 전표 제출(승인자용) 앱 타일에 상신 대기 건수가 카운터로 표시됩니다.
  • 2
    프로그램 실행 → 상신 목록 조회
    기본적으로 "나의 결재문서만"과 "미처리건"이 체크된 상태로 실행되면 본인 앞으로 온 미처리 상신 건이 표시됩니다.

결재내용 확인✅ 승인자

문서번호를 클릭하여 승인관리 화면으로 이동하고 상세 내역을 검토합니다.
  • 1
    문서번호 클릭 → 승인관리 화면 이동
    목록에서 문서번호를 클릭하면 승인관리 화면으로 이동합니다. 선택한 문서번호의 승인 내역 정보가 표시됩니다.
  • 2
    상세 내역 검토
    제출자가 입력한 연결 계정과목표·버전·전기정보·기안자 정보와 Document Title이 표시됩니다. 승인요청 당시의 디테일 그리드(자산코드·재무제표항목·금액 등)를 확인합니다.
📋 미처리 문서 (APPR_STAT_CD = 01)

승인 또는 반려 처리가 가능합니다. 그리드를 통해 상세 내역을 확인하고 결재를 진행합니다.

🔒 처리완료 문서 (APPR_STAT_CD = 02·03)

조회 기능만 지원합니다. 별도의 처리나 편집은 불가합니다.

6

승인 / 반려 처리✅ 승인자

검토 완료 후 승인 또는 반려를 처리합니다.

✅ 승인 처리

  • 1
    데이터 선택 → 승인 버튼
    내역을 선택하고 승인 버튼을 클릭합니다. "승인 하시겠습니까?" 다이얼로그가 표시됩니다.
  • 2
    승인 완료 → 승인상태 F
    승인 처리되면 해당 거래코드의 승인상태(ZWSTATUS)가 F로 업데이트됩니다. 제출자에게 승인 완료 알람이 발송됩니다.
    승인 상태 F인 건만 연결모니터에서 전표 생성이 가능합니다.
✅ 승인 후: 연결모니터 프로그램에서 상태를 확인하고 태스크를 실행할 수 있습니다.

❌ 반려 처리

  • 1
    데이터 선택 → 반려 버튼
    내역을 선택하고 반려 버튼을 클릭합니다. "반려 하시겠습니까?" 다이얼로그가 표시됩니다.
  • 2
    반려 완료 → 승인상태 X
    반려 처리되면 해당 거래코드의 승인상태(ZWSTATUS)가 X로 업데이트됩니다. 결재문서 상태가 빨간색으로 표시됩니다.
⚠ 반려 후 재요청: 반려된 건은 제출자가 다시 승인요청을 진행할 수 있습니다.
7

태스크 실행 (전표 전기)🖥️ 연결 모니터

승인(F)된 건에 대해 연결 모니터에서 태스크를 실행하여 GR 전표를 생성합니다.
✅ 실행 조건: 승인상태가 F(승인 완료)인 자산코드에 한해 태스크 실행을 통한 전표 전기가 가능합니다.
  • 1
    연결 모니터 접속
    SAP Group Reporting의 연결 모니터(Data Monitor 또는 Consolidation Monitor)를 실행합니다.
  • 2
    자산유형에 맞는 태스크 선택
    아래 전표유형에 따라 해당 태스크를 선택합니다.
  • 3
    태스크 실행
    선택한 태스크를 실행합니다. 연결 계정과목표·버전·회계연도/기간·연결그룹·연결단위 정보가 태스크 파라미터로 전달됩니다.
  • 4
    태스크 로그 확인
    태스크 로그에서 성공 시 전표번호를 확인합니다. 실패 시 관련 오류 메시지를 확인하고 원인을 조치합니다.
