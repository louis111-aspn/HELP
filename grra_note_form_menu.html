3.1.1 양식 및 메뉴관리

양식 및 메뉴관리

연결주석 작성에 사용할 주석양식을 생성하고, 양식 내에 주석메뉴를 트리 계층구조로 정의·관리하는 마스터 데이터 관리 화면입니다. 양식은 공시 세트 단위로 관리되며, 메뉴는 노드(그룹)와 양식(입력대상)으로 구분됩니다.

1

양식 조회

등록된 주석양식 목록을 조회합니다.
  • 1
    실행 버튼 클릭
    초기 화면에서 [실행] 버튼을 클릭하면 주석작성양식 테이블을 조회하여 등록된 양식 목록이 표시됩니다. 텍스트 테이블과 JOIN하여 양식명을 함께 표시합니다.
  • 2
    양식 세부사항 확인
    양식을 선택하면 하단에 해당 양식에 등록된 메뉴 목록이 트리 구조로 표시됩니다. 양식명, 작성주기, 생성된 메뉴 정보를 확인할 수 있습니다.

그리드 표시 항목

컬럼명테이블/필드비고
양식IDFORM_ID최초 생성 시만 입력, 이후 ReadOnly
양식명칭FROMTEXT언어별 텍스트 테이블 참조
작성주기CYCLEY:연간 / H:반기 / Q:분기 / M:월간
2

양식 신규 생성

새로운 주석양식을 생성합니다.
  • 1
    [생성] 버튼 클릭 → 신규 오브젝트 팝업
    양식ID(FORM_ID, 최대 10자, 중복 불가)와 작성주기를 입력합니다. [계속] 버튼을 클릭합니다.
  • 2
    양식명 텍스트 생성
    언어구분(KO/EN 등)을 선택하고 양식명칭을 입력합니다. [계속] → [적용]을 클릭하여 양식명을 확정합니다. 텍스트 테이블에 저장됩니다.
  • 3
    메뉴 구성 → 저장
    양식명 설정 후 메뉴를 생성합니다(→ 메뉴 신규 생성 참조). 구성 완료 후 [생성] 또는 [저장] 버튼을 클릭합니다.
⚠ 양식ID 제약: 양식ID(FORM_ID)는 최대 10자(공백 포함)이며, 생성 후에는 편집이 불가능합니다. 중복 입력 시 "키 값이 이미 사용 중입니다" 메시지가 표시됩니다.
3

양식 편집 및 삭제

기존 양식명을 수정하거나 양식을 삭제합니다.
✏️ 양식 편집

[편집] 버튼 클릭 시 양식명 편집이 활성화됩니다. 양식ID(FORM_ID)는 편집 불가(ReadOnly)입니다. 양식명은 텍스트 테이블에서 언어별로 관리됩니다.

🗑️ 양식 삭제

양식을 선택하고 [삭제]를 클릭합니다. 해당 양식에 속한 모든 메뉴 및 연결 데이터(레이아웃·주석 데이터 포함)가 연쇄 삭제됩니다. 경고 팝업 확인 후 진행합니다.

🚫 양식 삭제 시 연쇄 삭제 범위: (양식) → (메뉴) → (레이아웃) → (개별주석입력) → (개별마감) → (연결주석조회) → (연결마감) → (환산수식관리) → 각 텍스트 테이블이 모두 삭제됩니다.
4

메뉴 구조 조회

선택한 양식의 메뉴를 트리 구조로 조회합니다.
  • 1
    양식 드롭다운 선택 → [조회]
    주석양식을 드롭다운으로 선택한 후 [조회] 버튼을 클릭합니다. 해당 양식의 메뉴 구조가 트리 또는 테이블 형태로 표시됩니다.

메뉴 트리 구조 예시

▼ MENU0400  범주별 금융상품 [P: 노드]
┝ MENU0401  범주별 금융상품 내역 [L: 양식]
└ MENU0402  금융상품 범주별 순손익 구분 [L: 양식]

컬럼명테이블/필드비고
메뉴IDMENU_ID중복 불가
메뉴명칭MENUTEXT언어별 텍스트 테이블
상위메뉴IDPARENT_MENUP 타입 메뉴만 지정 가능

5

메뉴 신규 생성

새로운 주석 메뉴 항목을 생성합니다.
  • 1
    [편집] 버튼
    오른쪽 상단의 [편집] 버튼을 클릭하면 양식명 및 메뉴 편집이 활성화됩니다.
  • 2
    [신규] 버튼 → 신규 오브젝트 팝업
    하단에 입력행이 추가됩니다. 메뉴ID(중복 불가), 메뉴구분(노드/양식), 메뉴순서를 입력합니다.
  • 3
    메뉴 속성 설정
    행 우선 환산, 조회구분, 조정타입, 상위메뉴ID를 설정합니다. 상위메뉴 지정 시 메뉴구분이 자동으로 L(양식)로 설정됩니다.
  • 4
    메뉴명 텍스트 생성
    언어구분 선택 후 메뉴명을 입력합니다. [계속] → [적용]을 클릭하여 (메뉴텍스트 테이블)에 저장합니다.
  • 5
    [생성] 또는 [저장]으로 확정
    생성된 메뉴를 확인하고 [생성] 버튼을 클릭하여 저장합니다.
📌 메뉴순서 입력: 메뉴순서는 자동으로 부여되지 않습니다. 사용자가 직접 입력해야 하며, 저장 시 1-2-3처럼 연속된 숫자 체계인지 검증합니다.
6

메뉴 편집

기존 메뉴의 속성을 수정합니다.
  • 1
    [편집] 클릭 → 디테일 화면 이동
    편집할 메뉴를 선택하고 [편집]을 클릭하면 디테일 편집 화면으로 이동합니다.
  • 2
    수정 가능 항목 편집
    메뉴 속성을 수정합니다. 단, 연결된 입력 데이터가 존재하는 경우 메뉴순서만 편집이 가능합니다.
⚠ 편집 제한: 메뉴에 연결된 주석 입력 데이터·레이아웃이 존재하면 "해당 메뉴에 연결된 데이터가 존재합니다" 팝업이 표시되며 메뉴순서 외 항목은 편집 불가합니다.
⚠ 메뉴구분 변경 제한: 이미 하위 양식(L) 메뉴가 존재하는 노드(P) 메뉴의 메뉴구분을 L로 변경할 수 없습니다 ("리프 메뉴가 존재합니다" 오류).
7

메뉴 삭제

선택한 메뉴 항목을 삭제합니다.
삭제 대상조건처리 방식
양식 메뉴(L)데이터 없는 경우"삭제하시겠습니까?" → 확인 시 바로 삭제
노드 메뉴(P)하위 L 없는 경우"삭제하시겠습니까?" → 바로 삭제
노드 메뉴(P)하위 L 존재하는 경우"리프 메뉴가 존재합니다. 모두 삭제하시겠습니까?" → 확인 시 하위까지 연쇄 삭제
어떤 메뉴든연결 데이터 존재하는 경우"해당 메뉴에 연결된 데이터가 존재합니다" → 삭제 불가
🚫 메뉴 삭제 시 연쇄 삭제: (메뉴) → (레이아웃) → (주석데이터) → 각 텍스트 테이블이 해당 양식ID·메뉴ID 기준으로 모두 삭제됩니다.
8

저장

신규/편집/삭제한 메뉴 항목을 저장합니다.
  • 1
    변경사항 있을 때만 [저장] 활성화
    변경된 사항이 없으면 저장 버튼이 비활성화됩니다. 변경 후 "저장하시겠습니까?" 팝업이 표시됩니다.
  • 2
    저장 전 유효성 검증 자동 실행
    필수값 미입력 여부, 메뉴순서 연속성, 상위메뉴 유효성이 자동 검증됩니다. 오류 시 해당 셀이 빨간색으로 표시됩니다.
·

메뉴 속성 정의

메뉴 생성 시 설정하는 속성 항목 상세 정의입니다.
P
노드 (부모 메뉴)
하위 메뉴를 그룹화하기 위한 상위 구조 메뉴입니다. 실제 주석 데이터 입력·조회 불가. 하위 L 메뉴가 존재하면 L로 변경 불가합니다.
L
양식 (리프 메뉴)
실제 주석 데이터를 입력·조회하는 메뉴입니다. 반드시 상위메뉴(P)를 가져야 합니다(상위메뉴 없는 L은 저장 불가). 레이아웃관리·개별주석작성 대상입니다.
속성필드값설명
행 우선 환산ROW_CONVY / NY: 행 기준 환산 / N: 열 기준 환산 (기본값 N)
조회구분VIEWGUBUNS / YS: 합산조회 (기본값) / Y: 법인별 조회
조정타입ADJ_TYPET / CT: 합계조정 (기본값) / C: 셀단위 조정
·

유효성 검증 규칙

저장 시 시스템이 자동 검증하는 규칙 목록입니다.
검증 항목오류 조건메시지
양식ID 중복동일 FORM_ID 이미 존재"키 값이 이미 사용 중입니다. 다른 값을 입력하십시오."
양식ID 길이10자 초과"최대 10자(공백 포함)의 텍스트를 입력하십시오."
메뉴ID 중복동일 MENU_ID 이미 존재"메뉴 ID가 존재합니다"
상위메뉴 타입상위메뉴의 MENUGUBUN ≠ P"상위메뉴의 메뉴구분(P)을 확인하세요"
자기 자신을 상위메뉴로 지정MENUID = PARENT_MENU"자기 자신을 상위메뉴로 지정할 수 없습니다."
L 메뉴의 상위메뉴 없음PARENT_MENU IS INITIAL AND MENUGUBUN='L'"상위메뉴가 존재하지 않습니다."
