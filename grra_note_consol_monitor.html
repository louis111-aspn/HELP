3.3.1

연결주석모니터

개별 법인이 입력·마감한 주석 데이터를 연결그룹 기준으로 집계하고, 그룹통화로 환산하여 마감 처리하는 연결담당자용 프로그램입니다. 마감 처리된 메뉴는 집계·환산이 불가하며, 개별주석작성 모니터에도 마감이 반영됩니다.

순서 주의: 집계 → 환산 → (조정) → 마감 순서로 진행합니다. 마감 처리 후에는 집계 및 환산이 불가합니다. 최상위 노드 메뉴는 집계·환산·마감 상태를 관리하지 않습니다.
1

조회

연결그룹·버전 기준으로 메뉴별 집계·환산·마감 상태를 조회합니다.
  • 1
    조회 조건 입력 후 실행
    주석양식ID, 연결그룹, 연결버전, 회계연도, 회계기간을 입력합니다. 회계연도·기간은 글로벌 파라미터 기본값이 적용됩니다.
  • 2
    메뉴 트리 확인
    조회 결과로 메뉴 트리와 각 메뉴의 집계(Y/N/공란)·환산(Y/공란)·마감 상태가 표시됩니다.
2

집계

개별 법인이 마감한 주석 데이터를 연결그룹 기준으로 집계합니다.
  • 1
    집계 대상 메뉴 선택 → 집계 클릭
    집계할 메뉴를 선택하고 집계 버튼을 클릭합니다. 작성 마감된 법인의 데이터를 연결그룹 단위로 취합합니다.
  • 2
    집계 상태 확인
    집계 완료 시 집계 컬럼에 Y가 표시됩니다. 집계 후 법인의 데이터가 변경된 경우 N으로 표시되어 재집계가 필요함을 알립니다.

3

환산

집계된 로컬통화 데이터를 그룹통화로 환산합니다.
  • 1
    환산 클릭
    집계 완료(Y) 상태에서 환산 버튼을 클릭합니다. 레이아웃관리에서 설정한 CONV(환산구분) 기준(OPE·AVG·CLO·COPY·FORMULA)으로 그룹통화 금액이 산출됩니다.
  • 2
    환산 상태 확인
    환산 완료 시 환산 컬럼에 Y가 표시됩니다. ZGRADIS07T.VSTAT 필드에 Y로 저장됩니다.
4

조정

레이아웃의 연결참조(GSELECTION)를 기반으로 조정 데이터를 불러옵니다.
📌 조정 기능: 레이아웃 구성 시 연결참조를 설정한 항목의 조정 데이터(자동조정 CDS, GR총금액 CDS)를 불러와 ZGRADIS06T(연결주석조회 테이블)에 저장합니다. 연결주석조회 화면에서 해당 데이터를 확인할 수 있습니다.
5

마감 / 일괄마감

메뉴의 집계·환산·조정 작업을 마감합니다.
🔒 마감

선택한 메뉴의 마감 처리. ZGRADIS07T.CSTAT를 Y로 변경. 마감 후 집계·환산 불가. 개별주석작성모니터 메뉴도 자동 마감됨.

🔒 일괄마감 / 일괄마감 취소

조회된 모든 메뉴를 일괄 마감하거나 일괄 취소합니다.

🚫 마감 후 제한: 마감 상태에서는 집계·환산이 불가합니다. 개별주석작성모니터에서도 해당 메뉴의 마감 취소가 불가능해집니다.
