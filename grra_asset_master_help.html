상각자산 기준정보관리

그룹 내 법인 간 상각자산 내부거래(고정자산 미실현 · 공정가치 조정)에 대한 기준정보를 등록·관리하는 프로그램입니다. 거래자산 선택 시 상각자산 마스터관리에서 사전 정의된 계정정보가 자동 적용되며, 개별 생성·일괄 업로드·추가거래 등록·편집·삭제 기능을 제공합니다. 글로벌 매개변수(I_CnsldtnGlobalParameter)와 연동하여 연결 기준정보를 자동 초기화합니다.

A: 고정자산 미실현 / B: 공정가치 조정
UI 기술
SAP Fiori / SAPUI5 (RAP)

1

조회 화면 (초기 화면)

프로그램 실행 시 글로벌 매개변수 기반으로 조회 조건이 자동 세팅되고, 실행 버튼으로 기준정보 목록을 조회합니다.
📌 글로벌 매개변수 자동 초기화: 프로그램 실행 시 연결단위(매입법인)와 연결버전은 I_CnsldtnGlobalParameter에 설정된 값으로 자동 초기화됩니다. 이 값을 기본값으로 하되, 다른 법인 선택도 가능합니다.

2

기준정보 생성 (개별)

생성 팝업창을 통해 상각자산 기준정보를 한 건씩 등록합니다.
  • 1
    생성 버튼 클릭 → 팝업 열림
    생성 버튼을 클릭하면 팝업이 열립니다. 팝업 상단의 연결 계정과목표, 연결버전, 회계연도, 회계기간은 글로벌 매개변수 값으로 자동 세팅됩니다.
  • 2
    거래유형 선택
    거래유형 A 고정자산 미실현 또는 B 공정가치 조정을 선택합니다. 조회조건에 따라 전표유형 기본값이 달라집니다.
  • 3
    거래자산 선택 → 계정정보 자동 세팅
    거래자산(예: 건물_상각, 건물_공정가치)을 선택하면 상각자산 마스터관리 프로그램에 등록된 7개 계정(고정자산계정·상각계정·소거계정·상각누계계정·손상누계계정·손상차손계정·이연법인세계정)과 전표유형이 자동으로 채워집니다.
  • 4
    법인 정보 및 금액 입력
    판매(투자)법인과 매입(피투자)법인을 설정합니다. 매입법인은 글로벌 매개변수 기본값으로 편집이 불가합니다. 통화키도 매입법인에 맞춰 자동 세팅됩니다.
  • 5
    자산코드 자동채번 후 저장
    자산코드는 사용자가 직접 입력할 수 없으며, 저장 시 거래유형 코드 + 거래일자(YYMM) 조합으로 순번이 자동채번됩니다.

3

일괄 업로드

엑셀 템플릿을 활용하여 여러 건의 기준정보를 한 번에 등록합니다.
  • 1
    템플릿 다운로드
    일괄업로드 화면에서 템플릿 다운로드 버튼을 클릭하여 표준 엑셀 파일을 내려받습니다.
  • 2
    데이터 입력
    날짜 필드(거래일자, 상각일자)는 YYYYMMDD 형식으로 입력합니다. 거래유형, 계정 등 유효성 검사 규칙을 준수해야 합니다.
  • 3
    파일 업로드
    파일 탐색기에서 작성한 엑셀 파일을 선택하여 업로드합니다.
  • 4
    유효성 점검 → 저장 및 리스트 출력
    개별 생성과 동일한 유효성 점검이 실행됩니다. 오류 없이 저장되면 자산코드가 자동채번되고 조회 리스트에 즉시 출력됩니다. 오류가 있으면 해당 항목의 오류 내용을 확인하고 수정 후 재시도합니다.

4

편집

기존 기준정보의 내용을 수정합니다. 전표 생성 여부에 따라 편집 가능 범위가 달라집니다.
  • 1
    체크박스 선택 → 편집 버튼 클릭
    수정할 항목의 체크박스를 선택한 후 편집 버튼을 클릭합니다. 편집 팝업이 열리며 선택한 데이터의 값이 자동으로 불러와집니다.
  • 2
    편집 가능 범위 확인
    자산코드(거래코드), 거래유형, 그룹통화키는 항상 편집이 불가합니다. 계정·기간·연결단위는 전표 생성 여부에 따라 변경 가능 여부가 결정됩니다. 상태 필드는 활성화되어 편집이 가능합니다.
  • 3
    수정 후 저장
    수정 완료 후 저장하면 생성 시와 동일한 유효성 점검이 적용됩니다.
⚠ 편집 제한: 이미 전표가 생성된 경우 계정·기간·연결단위 등 핵심 필드의 변경이 제한될 수 있습니다. 전표 생성 여부를 반드시 확인한 후 편집을 진행하세요.
5

추가거래 등록

자산코드별로 손상(C) 또는 처분(D) 등의 변동 거래를 추가 등록합니다.
🚫 필수 선행 조건: 스케쥴 등록이 완료된 자산코드에 한해 추가거래 등록이 가능합니다. 스케쥴이 등록되지 않은 자산코드는 추가거래등록 버튼이 비활성화됩니다.
  • 1
    라인 선택 → 추가거래등록 클릭
    조회 그리드에서 대상 라인의 체크박스를 선택한 후 추가거래등록 버튼을 클릭합니다. 편집 중인 데이터가 있으면 먼저 편집을 완료해야 합니다.
  • 2
    라인추가 → 필수 항목 입력
    추가거래 화면에서 라인추가를 클릭합니다. 변동유형 ~ 거래적요까지 모든 항목을 입력해야 다음 라인 추가가 가능합니다.
  • 3
    저장
    저장 버튼을 클릭하면 PK 유효성 검증 후 ZGRAT5201 테이블에 저장됩니다. 메시지 필드에 검증 결과가 표시됩니다.

다운로드

조회된 기준정보 리스트를 엑셀 파일로 내려받습니다.

조회 화면에서 다운로드 버튼을 클릭하면 현재 그리드에 표시된 전체 데이터가 엑셀 파일로 다운로드됩니다. 데이터 백업, 오프라인 검토, 일괄업로드 재가공 등에 활용할 수 있습니다.

·

생성 유효성 검증 규칙

개별 생성 및 일괄업로드 저장 시 공통 적용되는 점검 항목입니다.
  • 🔴
    모든 필드 필수 입력: 생성 팝업의 모든 필드는 필수입니다. 빈 값이 있으면 저장되지 않습니다.
  • 📅
    상각일자 말일자 제한: 상각일자는 해당 월의 말일자만 허용합니다. 중간 일자 입력 시 오류가 발생합니다.
  • 💱
    통화환산 필수 (A 유형): 금액(LC) 입력 후 반드시 원화환산 버튼을 실행해야 저장됩니다. 원화환산 후 LC를 변경하면 반드시 재환산해야 합니다. LC와 GC 금액이 불일치하면 저장이 차단됩니다.
  • 📆
    기간 일치 검증: 글로벌 매개변수의 회계연도/기간과 입력한 거래일자·상각일자가 동일한 기간이어야 합니다. 미래 시점의 자산 등록은 불가합니다.
  • 🏢
    법인 동일 불가 (A 유형): 거래유형 A에서 판매(투자)법인과 매입(피투자)법인이 동일하면 오류가 발생합니다. 거래유형 B(공정가치 조정)는 동일 법인 입력이 가능합니다.
  • 🔑
    통화키 단일 선택 & 편집불가: 통화키는 매입법인의 통화에 맞춰 자동 세팅되며 편집이 불가합니다.
  • 📋
    공정가치 조정 전표유형 고정 (B 유형): 거래유형 B 선택 시 전표유형이 기본값으로 자동 지정되고 편집이 불가 상태로 전환됩니다.

거래유형 및 계정 구조

거래유형별 특성과 상각자산 마스터관리에서 자동 세팅되는 계정 구조입니다.
A
고정자산 미실현
상각자산 미실현 거래
그룹 내 법인 간 유·무형 고정자산 매각에서 발생하는 미실현손익을 소거하고 상각 처리하는 유형입니다.

원화환산(LC→GC) 기능을 지원하며, 판매법인 ≠ 매입법인이어야 합니다.

거래자산은 자산 종류 × 거래유형 조합으로 관리합니다 (예: 건물_상각).

Z1 — 연결조정 · 상각자산 미실현
Z2 — 연결조정 · 공정가치 조정
B
공정가치 조정
PPA 공정가치 조정 거래
사업결합(PPA) 시 식별 자산의 공정가치 조정분을 인식하고 이후 상각 처리하는 유형입니다.

거래자산은 자산 종류 × 거래유형 조합으로 관리합니다 (예: 건물_공정가치).
