3.2.2

주석작성 모니터

주석 메뉴별 법인별 작성 마감 현황을 조회하고, 법인별 또는 일괄로 마감 처리를 수행하는 프로그램입니다. 마감된 메뉴는 개별주석 작성 및 편집이 불가해집니다.

메뉴 경로
ASPN 주석관리 › 개별주석 관리 › 주석작성 모니터
주요 테이블
ZGRADIS05T (개별 마감관리)

📋 주요 프로세스 흐름

🔍
Step 1
조회 조건 입력 후 실행
📊
Step 2
메뉴 트리 및 진행률 확인
🏢
Step 3
상세 화면 → 법인별 마감
🔒
Step 4
마감 완료 → 편집 잠금
연결주석모니터 연계: 연결주석모니터에서 해당 메뉴를 마감하면, 이 화면의 메뉴도 자동으로 마감 처리되며 마감 취소가 불가능해집니다.
1

조회 및 메뉴 트리 확인

조회 조건을 입력하고 실행하면 메뉴 트리 구조와 마감 현황이 표시됩니다.
  • 1
    조회 조건 입력
    주석양식ID, 회계연도, 회계기간을 입력합니다. 회계연도·기간은 글로벌 파라미터 기본값이 적용됩니다. 메뉴ID는 Multi Parameter로 선택 가능합니다.
  • 2
    실행 → 메뉴 트리 조회
    실행을 클릭하면 양식 메뉴가 트리 구조로 표시됩니다. 노드 메뉴는 마감 상태를 관리하지 않으며, 양식(L) 메뉴만 마감 상태와 진행률이 표시됩니다.
  • 3
    상세 화면 이동 (> 버튼)
    양식 메뉴 우측의 > 버튼을 클릭하면 해당 메뉴의 법인별 마감 상세 화면으로 이동합니다.

2

법인별 마감 처리 (상세 화면)

개별 법인 단위로 마감 또는 마감 취소를 처리합니다.
  • 1
    상세 화면 진입
    메인 그리드에서 > 버튼을 클릭하면 해당 메뉴의 법인별 마감 상세 화면이 표시됩니다. 연결단위 목록과 각 법인의 마감 상태, 작성자, 작성일자가 표시됩니다.
  • 2
    법인 마감 클릭
    미마감 법인의 [마감] 버튼을 클릭하면 해당 법인의 ZGRADIS05T.CSTAT가 Y로 변경됩니다.
  • 3
    법인 마감 취소
    마감된 법인의 [마감취소] 버튼을 클릭하면 CSTAT가 공란으로 변경됩니다.

⚠ 연결주석모니터 마감 우선: 연결주석모니터에서 마감된 메뉴는 이 화면에서 마감 취소가 불가능합니다.
3

메뉴별 마감 (주석작성모니터 메인)

메인 그리드에서 개별 메뉴 단위로 전체 법인을 일괄 마감합니다.
  • 1
    메인 그리드 메뉴 선택 → [마감] 클릭
    메인 그리드의 양식 메뉴 행에서 [마감] 버튼을 클릭하면, 해당 메뉴를 사용하는 모든 연결단위가 일괄 마감됩니다. (상세 화면 이동 없이 즉시 처리)
4

일괄마감 / 일괄마감 취소

조회된 모든 메뉴에 대해 전체 법인을 한 번에 처리합니다.
🔒 일괄마감

조회된 모든 메뉴에 대해 해당 회계연도·기간의 전체 연결단위를 일괄 마감합니다. ZGRADIS05T.CSTAT를 Y로 일괄 업데이트합니다.

🔓 일괄마감 취소

조회된 모든 메뉴의 마감을 일괄 취소합니다. CSTAT를 공란으로 일괄 변경합니다.
