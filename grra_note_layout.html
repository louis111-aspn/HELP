3.1.2 주석 레이아웃관리

주석 레이아웃관리

양식 및 메뉴관리에서 생성된 양식 메뉴(L)의 주석 입력·조회 레이아웃을 구성하는 화면입니다. 행(ROW)과 열(COL)을 정의하고 각 항목의 환산구분·필드타입·표시여부 등 속성을 설정합니다. 수식 셀을 지정하여 다른 행/열 값의 계산 결과를 자동 산출할 수 있습니다.

선행 조건: 레이아웃을 설정하려면 양식 및 메뉴관리(3.1.1)에서 해당 양식과 양식 메뉴(L)가 먼저 등록되어 있어야 합니다. 레이아웃이 없는 메뉴는 개별주석 입력 화면으로 이동 불가합니다.
1

실행 및 조회

주석양식 ID와 메뉴 ID를 선택하여 레이아웃 화면을 실행합니다.
  • 1
    주석양식ID 선택
    도움창(F4)으로 ZGDT0010에 등록된 주석양식ID를 선택합니다.
  • 2
    메뉴ID 선택 → [실행]
    해당 양식의 메뉴ID를 선택하고 [실행]을 클릭합니다. 이미 레이아웃이 있으면 기존 행·열 구성이 표시됩니다.
📌 레이아웃 조회 방식: ZGRADIS03C(열)와 ZGRADIS03R(행)을 UNION하여 조회합니다. 행/열 구분 컬럼은 테이블에 없으므로 화면에서 구분하여 표시합니다.
2

행(ROW) 추가 및 속성 설정

주석 그리드의 행 항목을 추가하고 속성을 설정합니다.
  • 1
    [ROWS ADD] 클릭
    새로운 행이 추가됩니다. 행ID(ROW_ID)가 자동 부여됩니다.
  • 2
    행 속성 설정 팝업
    해당 행의 속성을 설정합니다. 다국어[A↔文] 버튼으로 행 레이블(명칭)을 언어별로 입력합니다.

행 속성 항목 (ZGRADIS03R)

속성명필드값/설명
레이블(명칭)ZGRADIS03R_LAN.ROWDE다국어 텍스트 (최대 200자)
사용여부ACTIVEY: 사용자 화면에 해당 행 표시
표시여부VISIBLEA: 모두 표시 / G: 연결주석조회만 / I: 개별주석조회만
자료구분DATATYPEA: 자동조정 / G: 총금액 / M: 매뉴얼 조정
환산구분CONVAVG/CLO/OPE/COPY/FORMULA (행 우선 환산 적용 시)
입력참조SELECTION개별주석 입력 시 검증 기준 재무제표 항목
연결참조GSELECTION연결주석 조정 데이터·GR총금액 조회 기준
3

열(COL) 추가 및 속성 설정

주석 그리드의 열 항목을 추가하고 속성을 설정합니다.
  • 1
    [COLUMNS ADD] 클릭
    새로운 열이 추가됩니다. 열ID(COL_ID)가 자동 부여됩니다.
  • 2
    열 속성 설정 팝업
    열 레이블과 속성을 설정합니다. 행 속성과 대부분 동일하나 필드타입(FIELDTYPE)이 추가됩니다.

열 전용 추가 속성 (ZGRADIS03C)

속성명필드값/설명
레이블(명칭)ZGRADIS03C_LAN.COLDE다국어 텍스트 (최대 200자)
필드타입FIELDTYPEAMT01~10 / TXT01~16 / DATE / NUM / QUAN / VALID
통화구분CURRL: 로컬통화 / T: 거래통화
단위값UOM수량 단위 (KG, EA 등)
통화단위 참조REF_TXTCURR=T일 때 활성화. 통화값을 참조할 TXT 타입 열 지정
환산구분CONV열 기준 환산 적용 시 (행 우선 환산=N인 메뉴)
📌 행·열 우선순위: 동일 속성(환산구분 등)이 행과 열 양쪽에 설정된 경우, 메뉴의 행 우선 환산(ROW_CONV) 설정에 따라 행 또는 열 속성이 우선 적용됩니다.
⚠ 수식 → 일반 데이터 변경 시: 수식(FORMULA) 환산구분이 설정된 셀에 일반 데이터로 변경하면 기존 행·열의 CONV(환산구분) 값이 삭제됩니다.
4

수식(Formula) 설정

특정 셀의 값을 다른 행·열 값의 계산 결과로 자동 산출되도록 수식을 지정합니다.
  • 1
    수식을 적용할 셀 선택
    그리드에서 수식을 입력할 셀(행·열 교차 지점)을 클릭합니다.
  • 2
    [서식 편집] 클릭
    [서식 편집] 버튼을 클릭하면 수식 입력 팝업이 열립니다.
  • 3
    수식 입력 → [저장]
    함수 및 변수 입력창에서 사칙연산(+, -, *, /)으로 계산식을 작성합니다. 완료 후 [저장]을 클릭합니다. ZGRADIS03F(수식 테이블)에 저장됩니다.
📌 수식 우선 적용: 행·열 레이아웃의 CONV(환산구분)를 FORMULA로 설정한 후 이 수식 설정을 통해 환산수식관리(3.3.3)에서 구체적인 수식 멤버를 정의합니다.
5

레이아웃 저장

구성한 레이아웃을 확정 저장합니다.
  • 1
    [레이아웃 저장] 클릭
    레이아웃 구성을 완료한 후 [레이아웃 저장] 버튼을 클릭합니다. 행 데이터는 ZGRADIS03R, 열 데이터는 ZGRADIS03C, 수식은 ZGRADIS03F에 저장됩니다.
⚠ 저장 전 확인사항: 레이아웃 저장 후 개별주석 데이터가 입력된 상태에서 행·열을 추가/삭제하면 기존 데이터와의 정합성이 깨질 수 있습니다. 운영 중에는 레이아웃 변경을 최소화하십시오.
·

환산구분 코드 정의

연결주석 모니터 환산 시 적용되는 환율 기준 코드입니다.
OPE
기초환율
기수(期首) 환율 적용. 기초잔액 관련 항목에 사용.
AVG
평균환율
해당 기간의 평균환율 적용. 손익 항목에 주로 사용.
CLO
기말환율
기말(期末) 환율 적용. 재무상태표 항목에 사용.
COPY
LC금액 복사
환율 환산 없이 로컬통화(LC) 금액을 그대로 복사.
FORMULA
수식 환산
환산수식관리(3.3.3)에서 정의한 수식으로 환산. 다른 행/열 값의 계산 결과를 사용.

필드타입 정의

열(COL)의 FIELDTYPE 값 및 ZGRADIS04T 저장 필드와의 매핑입니다.
AMT01 ~ AMT10
금액 필드. 대응 통화: CURR01~CURR10
TXT01 ~ TXT16
텍스트 필드. 거래통화(T) 입력 시 통화코드 보관에도 사용
DATE
일자 (YYYYMMDD 형식)
NUM
숫자 (통화 없는 수치)
QUAN01 ~ QUAN10
수량 필드. 대응 단위: UNIT01~UNIT10
VALID
검증 열 (자동 계산 결과 표시)
📌 AMT ↔ CURR 참조: AMT01은 CURR01, AMT02는 CURR02를 참조합니다. QUAN01은 UNIT01, QUAN02는 UNIT02를 참조하는 방식으로 쌍으로 관리됩니다.
·
