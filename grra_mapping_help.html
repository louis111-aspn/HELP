PG-DC-0010

재무제표 항목과 Non-SAP G/L 계정 매핑

Non-SAP 법인(연결 단위)의 G/L 계정 코드를 SAP Group Reporting의 재무제표 항목(FS Item)과 연결·관리하는 프로그램입니다. 엑셀 업로드 기반의 임포트, 버전 관리(개정), 효력기간(지정) 설정을 통해 연결결산 데이터의 무결성을 확보합니다.

1

조회 화면 (초기 화면)

프로그램 실행 시 표시되는 기본 화면으로, 조회 조건 입력 후 매핑 목록을 조회합니다.
  • 1
    프로그램 실행
    프로그램을 실행하면 조회 조건 입력 영역과 결과 그리드가 표시됩니다. 초기에는 업로드된 데이터가 없으면 "사용 가능한 데이터가 없음" 메시지가 반환됩니다.
  • 2
    조회 조건 입력 후 실행
    조회 조건(연결단위, 연결 계정과목표, 매핑ID, 개정)을 입력하고 실행 버튼을 클릭하면 해당 조건에 맞는 데이터가 그리드에 표시됩니다.
  • 3
    상세 내역 이동
    그리드 각 행 오른쪽의 > 버튼을 클릭하면 해당 매핑의 G/L 계정 상세 내역(편집 화면)으로 이동합니다.

2

매핑 생성

새로운 매핑 ID를 생성합니다. 임포트 전 반드시 선행되어야 합니다.
  • 1
    매핑 생성 버튼 클릭
    조회 화면 상단의 매핑 생성 버튼을 클릭하면 팝업 창이 표시됩니다.
  • 2
    필수 정보 입력
    아래 필드를 입력합니다.
필드필수여부설명
매핑 ID (MappingId)필수단일값(Single Value). 법인당 하나의 매핑 ID만 존재 가능
매핑 내역(로컬) (MappingTextLo)필수매핑명 (로컬 언어)
매핑 내역(그룹) (MappingTextGr)필수매핑명 (그룹 언어)
UUID / 생성일시 / 생성자자동시스템이 자동 생성
⚠ 주의: 한 개의 연결단위에는 하나의 매핑 ID만 존재할 수 있습니다. 계정은 중복 생성할 수 없습니다.
  • 3
    생성 버튼 클릭 → 저장
    입력 완료 후 생성 버튼을 클릭하면 ZGRTCOA01 테이블에 저장됩니다.
3

개정 생성

기존 매핑 ID에 새로운 버전(개정)을 추가합니다. 매핑 생성 이후 선행되어야 임포트가 가능합니다.
  • 1
    개정 생성 버튼 클릭
    조회 화면 상단의 개정 생성 버튼을 클릭하면 팝업 창이 표시됩니다.
  • 2
    필수 정보 입력
    매핑 ID 선택 후 개정 번호(숫자만 허용)를 입력합니다. UUID, 생성일시, 생성자는 시스템이 자동 처리합니다.
  • 3
    저장
    ZGRTCOA02 테이블에 저장됩니다. 개정 추가 후 팝업은 자동 닫힙니다.
📌 개정 번호 규칙: 개정 번호 규칙: 개정 필드에는 숫자만 입력 가능합니다. 텍스트는 입력할 수 없도록 제한되어 있습니다.
4

지정 (효력기간 관리)

연결단위 / 매핑 ID / 연결 버전별로 효력 기간을 설정하고 관리합니다.
  • 1
    라인 선택 후 지정 버튼 클릭
    조회 그리드에서 대상 라인을 선택한 후 지정 버튼을 클릭합니다. 해당 연결단위/매핑 ID에 등록된 효력기간 리스트를 확인할 수 있습니다.
  • 2
    신규 지정: 효력 시작일 입력
    효력 시작일(FyearperiodTo)을 입력하면 시스템이 자동으로 효력 종료일(FyearperiodFr)을 계산합니다.

5

임포트 (계정 업로드)

Non-SAP 법인의 G/L 계정 내역이 담긴 엑셀 파일을 업로드합니다.
📌 선행 조건: 임포트 전에 반드시 ① 매핑 생성 → ② 개정 생성이 완료되어 있어야 합니다.
  • 1
    임포트 버튼 클릭
    조회 화면 상단의 임포트 버튼을 클릭하면 임포트 팝업(Screen3)으로 이동합니다.
  • 2
    템플릿 다운로드
    다운로드 버튼을 클릭하여 표준 엑셀 업로드 템플릿 파일을 내려받습니다.
  • 3
    파일 선택 (찾아보기)
    찾아보기 버튼을 클릭하여 업로드할 엑셀 파일을 선택합니다. 파일 탐색기 창이 열립니다.
  • 4
    매핑 개정 라인 선택 후 임포트
    리스트에서 대상 매핑 개정 라인을 선택한 후 임포트 버튼을 클릭합니다. 라인을 선택하지 않은 경우 임포트 버튼이 비활성화됩니다.
  • 5
    오류 처리
    업로드 과정에서 오류 발생 시 화면에 오류 메시지가 반환됩니다. 엑셀 파일을 수정한 후 재시도합니다.
⚠ 주의: 연결항목(isConsolidationItem = '예')으로 설정된 재무제표 항목은 Non-SAP 매핑 대상에서 제외됩니다. 해당 항목 매핑 시도 시 "연결 전용 항목은 매핑할 수 없습니다" 오류 메시지가 반환됩니다.

  • 3
    저장 (유효성 검증 후 확정)
    저장 버튼 클릭 시 데이터 유효성 검증이 실행됩니다. 검증 통과 시 ZGRTCOA04 (액티브 테이블)에 최종 반영됩니다. 오류 발생 시 화면에 오류 메시지가 표시됩니다.
  • 4
    취소
    취소 버튼 클릭 시 변경 사항을 저장하지 않고 이전 상태로 돌아갑니다.
